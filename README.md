Sitemas da Informação Chapeco

Baixe o projeto diretamente do meu repositório do GitHub,

Após isso coloque ele em um servidor local como o XAMMP

C:\xampp\htdocs\
Abra o painel do XAMPP e clique em Start no Apache.

no seu navegador acesse http://localhost/site/cadastro.php

Vá para cadastro.php  preencha nome, e-mail e senha

Faça login em login.php

Use logout.php para sair da sessão
